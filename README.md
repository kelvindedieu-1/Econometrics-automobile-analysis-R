Econometrics analysis and modelling of automobile consumption with R language
# Econometric Analysis of Automobile Data using R

This project focuses on identifying and modeling the key determinants of vehicle fuel efficiency (`mpg`) and pricing. It utilizes exploratory data analysis, statistical hypothesis testing, and multiple linear regression models.

# Methodology & Key Analyses
- **Descriptive Statistics:** Conducted exploratory data analysis (EDA) to understand distribution, variances, and correlations across pricing and fuel metrics.
- **Hypothesis Testing:** Applied One-Sample T-Tests and Analysis of Variance (`ANOVA`) to evaluate mean differences across vehicle groups based on their origin (domestic vs. foreign).
- **Predictive Modeling:** Built and evaluated multiple linear regression models using Ordinary Least Squares (`OLS`) to measure the impact of vehicle weight, length, and origin on fuel consumption.

# Technologies & Tools
- **Language:** R (Base R modeling functions: `lm`, `t.test`, `anova`)
- **Planned Extensions:** Econometric panel data modeling via the `plm` package.
